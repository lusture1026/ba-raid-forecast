# 蔚蓝档案总力战通关人数预测器（B服 / 官服）

预测蔚蓝档案（Blue Archive）国服总力战**最高难度（TM）及以上通关人数**、**一档线落带**与**一档线跌落时刻**的本地脚本。数据来源：[什亭之匣 arona.icu](https://arona.icu)。

## 它回答什么

每期总力战期间运行，回答三个问题：

1. 本期 TM 及以上（含更高难度）最终会有多少人通关？（中位数 + 误差区间）
2. 一档线（B服前 8,000 名 / 官服前 20,000 名）会卡在哪个档位？TM 带、满分带还是打穿带？
3. 若发生"一档线跌落"（TM 玩家挤掉满分带玩家），最可能发生在什么时候、贴线玩家会掉到多少名？

## 快速开始

```bat
双击运行预测.bat
```

或命令行：`python 总力战预测.py`（加 `-v` 查看计算细节）。需要 Python 3.8+，首次运行自动安装 `wasmtime` 依赖。

- **赛期内每天跑一两次即可**，越接近结算数字越准。
- 脚本会**自我学习**：发现新一期已定榜且历史库中没有时，自动拉取定榜数据并入 `历史基准.json`（写入前自动备份 `.bak`），无需手动维护。
- 详细读数方法与行动建议见 [预测器使用说明.md](预测器使用说明.md)。

## 预测原理（三句话版）

- **跟上一期比**：同 Boss 同地图上次通关人数 × 历届复刻的增速规律。历史硬规律：成熟期同格复刻从未下降（最小 +15%）——开战初期数据少时靠它兜底。
- **按目前进度推**：上期同一时刻通关了多少人，本期是它的几成，按比例推到底。开战 60 小时后误差快速收窄（最后 48 小时仅个位数百分比），此后由它主判。
- **看历次挤门槛的先例**：历史上名额线被穿越的时刻全部在案（B服 3 次分别在结算前 50/5/9 小时），跌落窗口直接以真实先例为锚，并按"超额幅度越大穿越越早"的规律（官服 9 次先例验证）给方向提示。

档位判定用"阶梯"：TM及以上 ≥ 名额 → TM带；否则满分线及以上 ≥ 名额 → 满分带；否则打穿线及以上 ≥ 名额 → 打穿带。其中次高难度人口不读站点计数器（千位取整），改由名次线分数轨迹夹逼插值间接推断。

每次预测附带**可信度自评**（★1~5），依据数据龄、两种方法是否一致、区间宽度、是否骑线等因素——低于三星表示"下结论还太早，以区间为准"。

## 项目结构

```
├── 总力战预测.py                      # 主程序（单文件，无本地依赖）
├── 双击运行预测.bat                    # Windows 双击启动
├── yuyuko.wasm                        # 什亭之匣接口加解密模块（来自 arona.icu 站点前端）
├── 历史基准.json                       # 历史定榜数据库（s15 起，脚本自动增补）
├── 预测器使用说明.md                    # 通俗版使用方法 + 行动指南
├── 预测结果.md / index.md              # 最新预测报告（Actions 自动更新；index.md 供 Pages）
├── .github/workflows/predict.yml      # 定时预测工作流（北京时间 02/04/08/14/20 点）
├── README.md
└── .gitignore                         # 运行时产物（预测结果.txt / *.bak）不入库
```
